THE PROBLEM

When the canal runs dry, the aquifer pays the price

What's happening

  • Tail-end deficits along the Lower Ganga Canal push farmers toward unmetered private tubewell drilling — the only backup supply they control.
  • Two authorities — the Irrigation Department and the Groundwater Department/CGWB — manage one connected hydrological system with zero shared, real-time data.
  • Prayagraj is a documented groundwater-mining hotspot, with no local instrumentation to catch drawdown before it compounds.

Who's affected, and why it matters

  • Tail-end smallholder farmers absorb yield loss and rising diesel-pumping costs every time the canal underdelivers.
  • UP Irrigation Dept. engineers cannot manually police an ~8,183 km distributary network for equity.
  • Groundwater is already the dominant irrigation source in UP — so a canal failure here is really a shared-aquifer failure.
Why I chose this: the Lower Ganga Canal's own tail district is Kaushambi, right next to Prayagraj — this isn't a hypothetical site picked for a project. It's the ground I actually stand on.
THE AI-ENABLED SOLUTION

Predicting deficits before they happen

JalSetu links canal-flow sensors and groundwater piezometers to a forecasting model that predicts a water deficit 24–48 hours ahead — recommending a gate adjustment before the tail end runs dry, instead of reacting after it already has.

How AI is used

A time-series LSTM model ingests canal discharge, groundwater depth, and weather data to output a Predicted Deficit Index — the core prediction driving every downstream decision.

Key features

Proportional gate actuation (not blunt on/off), a human-in-the-loop override retained at every step, and an edge-fallback to safe threshold logic if connectivity drops.

Tools & technologies used

PythonHTML / CSS / JSLSTM (time-series forecasting) LoRaWAN + MQTT (IoT layer)
